# Student CRM

Небольшое учебное приложение на React для отображения списка студентов. Проект создан для практики компонентов, передачи данных через props, рендеринга массивов и условного отображения информации.

## Возможности

- показывает список студентов;
- отображает имя, возраст и группу студента;
- показывает статус: «Активен» или «Пауза»;
- показывает общее количество студентов;
- выводит сообщение, если список пуст;
- отмечает студентов младше 18 лет;
- использует отдельные компоненты для списка, карточки и статуса.

## Структура компонентов

```text
App
├── Header
├── StudentList
│   └── StudentCard
│       └── StatusBadge
└── Footer
```

Данные студентов передаются в компоненты через props. Список карточек формируется из массива с помощью `map()`, а в качестве `key` используется уникальный идентификатор студента.

## Данные студента

Карточка использует поля объекта студента:

- `id` — уникальный идентификатор;
- `name` — имя;
- `age` — возраст;
- `group` — группа;
- `isActive` — активен ли студент.

Сами записи студентов находятся в исходном коде приложения. Этот README описывает поля данных без отдельной копии списка, чтобы примеры не расходились с актуальными данными приложения.

## Запуск проекта

В терминале перейдите в папку проекта и выполните:

```bash
npm install
npm run dev
```

Затем откройте адрес, который Vite покажет в терминале.

## Сборка

```bash
npm run build
```
